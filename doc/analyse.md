**Analyse**

_User Stories:_
US 1: Als student wil ik studiesessies op kunnen slaan, zodat ik weet hoeveel studiesessies ik heb gedaan.

US 2: Als student wil ik alle onderwerpen dat ik studeer op kunnen slaan, zodat ik weet welke onderwerpen ik heb bestudeerd.

US 3: Als student wil ik alle deelonderwerpen per onderwerpen dat ik studeer op kunnen slaan, zodat ik weet welke deelonderwerpen ik heb bestudeerd.

US 4: Als student wil ik een overzicht van alle studiesessies kunnen zien, zodat ik overzicht krijg op al mijn studiesessies.

US 5: Als student wil ik een overzicht van een studiesessie kunnen zien, zodat ik weet hoe lang ik elk deelonderwerp gestudeerd heb.

US 6: Als student wil ik een overzicht, waarin ik per onderwerp kan zien hoeveel tijd ik er in totaal aan heb besteed, zodat ik weet hoe lang ik heb gestudeerd voor dat onderwerp.

US 7: Als student wil ik een overzicht, waarin ik per onderwerp van de deelonderwerpen kan zien hoeveel tijd ik er in totaal aan heb besteed, zodat ik weet hoe lang ik heb gestudeerd voor dat onderwerp.

US 8: Als student wil ik een overzicht, waarin ik kan zien wat ik in de laatste periode heb gestudeerd per (deel)onderwerp, om zo snel een geschiedenis te kunnen zien van mijn laatst gestudeerde (deel)onderwerpen.

US 9: Als student wil ik een studiesessie kunnen starten met een studietimer die mij om de zoveel tijd een signaal geeft, zodat ik weet dat ik het volgende onderwerp moet gaan studeren.

US 10: Als student wil ik zelf notities kunnen toevoegen bij een bepaald deelonderwerp, om zo snel aantekeningen te kunnen maken.

US 11: Als student wil ik een overzicht, waarin ik de notities kan zien die ik wil zien, om zo snel mijn aantekeningen te benaderen.

US 12: Als student wil ik een timer van een onderwerp ook eerder kunnen afkappen en de tijd opslaan, zodat ik precies weet hoeveel tijd ik daadwerkelijk aan dat onderwerp heb besteed.

US 13: Als student wil ik bij het instellen van mijn sessie, suggesties voor deelonderwerpen krijgen, om zo sneller aan de slag te kunnen gaan.

US 14: Als student wil ik een soor shuffle functionaliteit, waarmee ik snel de deelonderwerpen van een onderwerp kan bestuderen op een willekeurig volgorde.

US 15: Als student wil ik 'playlists' op kunnen slaan, met daarin een vaste volgorde van deelonderwerpen, zodat ik een sessie kan herhalen.

US 16: Als student wil ik een ringtoon kunnen toevoegen als mijn alarm, om zo meer personaliteit erin te verwerken.

US 17: Als student wil ik een lied of nummer kunnen toevoegen als mijn bgm, om zo meer personaliteit erin te verwerken.
